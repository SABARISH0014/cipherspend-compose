At CipherSpend, we believe that your personal financial records are sacred, sensitive, and private. Unlike traditional expense management services that upload your banking history to remote servers or monetize your data through ad networks, CipherSpend was engineered from day one on a foundation of strict Zero-Knowledge, 100% Offline execution.

This Privacy Policy and Prominent Disclosure describes in clear, transparent language how CipherSpend handles data, why sensitive Android permissions are requested, how your data is cryptographically safeguarded on your hardware, and how you retain total sovereignty and control over your financial records.

2. 100% Offline Architecture & Absence of Internet Access

The cornerstone of CipherSpend’s security guarantee is architectural, not merely contractual:

Absolute Technical Guarantee: CipherSpend does NOT declare or request the android.permission.INTERNET permission in its Android Manifest (AndroidManifest.xml). The operating system itself physically prohibits CipherSpend from establishing any network sockets, HTTP/HTTPS connections, or remote communications.

🚫 Zero Remote Infrastructure

  • No cloud servers, sync relays, or databases
  • No remote APIs, telemetry, or diagnostic beacons
  • No user accounts, email logins, or tracking IDs

🚫 Zero Third-Party SDKs

  • Zero advertising SDKs or programmatic ad networks
  • Zero analytics frameworks (No Firebase, No Mixpanel)
  • Zero crash-reporting SDKs that upload logs

Because there is literally no network interface in the application bundle, it is mathematically and physically impossible for your financial records, bank messages, or identity to be exfiltrated or transmitted to anyone—including the developer.

4. Military-Grade Local Cryptography (SQLCipher AES-256)

When transaction data is parsed, it is immediately protected by multiple layers of hardware-backed encryption:

  • SQLCipher AES-256 Encryption: All transactions, budget limits, notifications, and metadata are written into an encrypted SQLite database (cipherspend_encrypted.db) using 256-bit AES encryption with HMAC-SHA256 page authentication and 256,000 PBKDF2 key derivation iterations.
  • Hardware-Backed Android Keystore: Master cryptographic encryption keys and user preferences are secured via Android Keystore system with EncryptedSharedPreferences using the AES256_GCM master key scheme, ensuring hardware-isolated protection against root compromise or external extraction.
  • Zero-Knowledge Master MPIN: The user’s 4-digit Master MPIN is salted and hashed using PBKDF2. The application never stores your plaintext MPIN.
  • Memory Protection: Direct in-memory ByteBuffer buffers are cleared and recycled to prevent memory dumps or cold-boot exposure.

5. User Control, Offline Backup & Right to Erasure (GDPR / CCPA)

CipherSpend guarantees complete, unfettered user sovereignty over financial data in accordance with global data protection standards (including GDPR and CCPA principles):

💾 Local Vault Backup & Restore

Users can export their complete encrypted ledger to a local JSON file at any time via the Android Storage Access Framework (SAF). Backups can be restored across devices completely offline without internet or cloud accounts.

💥 Complete Nuclear Wipe (Data Erasure)

Tapping "Delete Account & Data" in Settings immediately wipes the SQLCipher database file (cipherspend_encrypted.db), purges all cryptographic keys from the Android Keystore, erases preferences, and resets the application to a clean state.

  • Revoking Permissions: You can revoke SMS or Notification Listener permissions at any time via Settings > Apps > CipherSpend > Permissions without bricking manual ledger features.
  • Individual Transaction Deletion: Swipe left on any transaction row in the dashboard to delete it immediately, with instant one-tap undo capability.
